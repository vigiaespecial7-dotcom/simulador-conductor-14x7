# Simulador gerencial costo conductor 14x7

Dashboard web gratuito en Streamlit para proyectar cuánto cuesta un conductor bajo esquema 14x7.

## Qué calcula

- Salario base / SMLV
- Sin auxilio de transporte
- Bono disponibilidad
- Bono resultados
- Bono comunicación
- Bono variable por facturación
- Extras diurnas
- Extras nocturnas
- Recargo nocturno
- Dominicales/festivos
- Carga empresa estimada
- Costo mensual por conductor
- Costo total por cantidad de conductores
- Costo anual proyectado
- Calendario operativo 14x7

## Archivos

- app.py
- requirements.txt
- README.md

## Cómo subirlo a Streamlit Community Cloud sin instalar nada

1. Entra a GitHub desde navegador.
2. Crea o abre tu repositorio.
3. Sube estos tres archivos:
   - app.py
   - requirements.txt
   - README.md
4. Entra a Streamlit Community Cloud.
5. Crea una nueva app.
6. Selecciona el repositorio.
7. En Main file path escribe:
   app.py
8. Haz clic en Deploy.

## Nota

Este simulador es gerencial y de proyección. No reemplaza una liquidación oficial de nómina.
